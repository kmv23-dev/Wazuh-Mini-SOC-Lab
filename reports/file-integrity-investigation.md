# Investigation 2 — File Integrity Monitoring

**Date:** October 18, 2026  
**System:** Windows 11 lab endpoint monitored by Wazuh Cloud  
**Classification:** Authorized file-change test; no confirmed security incident

## Objective
Configure a monitored folder and verify that Wazuh detects file creation and modification.

## Configuration and test
Verified `<disabled>no</disabled>` under the Wazuh agent's `syscheck` configuration. Created `C:\Wazuh-FIM-Lab` and added the following directory to the agent's FIM configuration:

```xml
<directories realtime="yes">C:\Wazuh-FIM-Lab</directories>
```

After restarting the Wazuh agent, I created `test.txt` containing a harmless test string and appended another line.

## Observations
- **Creation:** `syscheck.event: added`, rule `554`, level `5`, `File added to the system.`
- **Modification:** `syscheck.event: modified`, rule `550`, level `7`, `Integrity checksum changed.`
- **Path:** `c:\wazuh-fim-lab\test.txt` in both events.
- **Changed attributes reported for modification:** `size`, `mtime`, `md5`, `sha1`, `sha256`.

## Analysis and disposition
The two events matched the expected creation and modification of the test file. FIM can help identify unexpected file changes, but a checksum change alone does not establish malicious activity. These alerts were generated by an authorized lab test.

**Recommended disposition:** Document and close the known test alerts. In production, investigate unexpected changes to sensitive files and correlate with user, process, and system activity.
